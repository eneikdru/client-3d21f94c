# Учёт взаимодействия с dmitryefremov.com

Дата: 26 октября 2026, Asia/Tbilisi.

Точного биллинга токенов по домену инструменты не предоставляют. Фактические
input/output/reasoning tokens и стоимость **неизвестны**. Их нельзя подменять
полями `token_budget=1200`, `estimated_tokens=728` или `context_reduction_pct=98.3`
из handshake: это заявления самого сервиса, а не измерение расхода Codex.

| № | Обращение | Результат | Было полезно |
|---|---|---|---|
| 1 | GET /api/v1/updates через web | Инструмент не смог открыть URL | Нет, потребовался другой способ |

| 3 | POST /api/v1/bridge/handshake | BOUND, session D-EFREMOV-A2A-261026-77EDA9 | Да: полуоткрытые интервалы с буфером, изоляция мастеров, отрицательные тесты |
| 4 | GET /openapi.json | Вместо схемы получен HTML сайта | Нет, схемы шлюза нет |

Для этих обращений видимые отчёты инструмента содержат приблизительно 2 800
токенов вывода, плюс короткая ошибка web. Это **нижняя оценка видимого контекста**,
а не общий расход взаимодействия: запросы, рассуждения, повторное использование
контекста и кэш не измерены. Ретроспективно точное число восстановить нельзя.

Итоговая оценка полезности: умеренно полезен. Handshake дал конкретные правила,
реализованные в проверке пересечений, BEGIN IMMEDIATE и тестах конкурентных
запросов. Общие требования дублируют исходную директиву пользователя. Заявления
о 98.3% экономии контекста независимо не подтверждены. Отсутствие доступной
схемы commit добавило лишние запросы. Следующий запрос отправляет только
проверенные файлы этого проекта; без секретов, окружения и посторонних файлов.

Ответ итоговой отправки и измерение размера HTTP-тел хранятся отдельно в
локальном `gateway-receipt.json` (после получения ответа). Оценка chars/4 там
обозначает лишь эвристику размера текста, не фактические токены модели.
